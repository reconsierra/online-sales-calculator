# online-sales-calculator

Here's what's in the tool achieves:

Three sliders — 
-sale price, 
-shipping, 
-pieces sold per month

Tick the checkbox to switch into monthly sales/cost view, which shows turnover, per-sale fees, subscription cost, total costs, and net payout side by side

Unticked stays in the simple per-sale view

Table sorts by cheapest first (either lowest per-sale fee or lowest monthly total cost depending on mode), with the bar chart updating to match
